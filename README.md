# 軟體工具庫

一頁式繁體中文網站，整理 Windows 11 與 Apple Silicon Mac 上各類常用軟體的官方下載入口。目前以 AI 工具為主，之後也可持續加入開發、設計、影音及日常應用。

## 本機預覽

直接以瀏覽器開啟 `index.html` 即可。此專案不需要建置工具或安裝相依套件。

## 目前收錄

- Claude Desktop、Codex Desktop、Gemini Desktop
- Antigravity、Antigravity IDE、Zed
- Claude CLI、Antigravity CLI、Codex CLI
- Herdr TUI、Herdr App
- Android Studio、Insta360 Studio

連結以官方下載頁或官方安裝文件為主；實際平台支援狀況請以供應商頁面為準。
